## Chạy lại và nghiệm thu thật

Sửa môi trường dependency bằng terminal thông thường có mạng (tại root repo):

```powershell
npm.cmd ci
npm.cmd run build -w @toeic/common
foreach ($s in @('auth','question-bank','exam','learning','analytics')) {
  npm.cmd run prisma:generate -w "@toeic/$s-service"
  if ($LASTEXITCODE -ne 0) { throw "Generate failed: $s" }
  npm.cmd run build -w "@toeic/$s-service"
  if ($LASTEXITCODE -ne 0) { throw "Build failed: $s" }
}
npm.cmd run build -w @toeic/api-gateway
```

Không chạy migration cutover lên DB cũ chỉ để vượt lỗi. Năm DB test của phiên đã migrate; launcher dưới đây chỉ dùng chúng, không migrate/seed/reset. Cần hạ tầng local và Mailpit đang chạy. Launcher từ chối cổng đang bị giữ và thiếu dependency/bản build; lấy cấu hình dịch vụ hiện hữu, thêm giá trị mẫu còn thiếu trong **process env**, không ghi đè file `.env`.

```powershell
$runOut = 'tmp/frontend-local-manual-' + (Get-Date -Format yyyyMMdd-HHmmss)
node scripts/qa/frontend-local-stack.cjs --databases tmp/frontend-integration-session34-20261103/isolated-databases.json --out $runOut --frontends --writes
```

Web: <http://localhost:3006/login>; CMS: <http://localhost:3007/login>; Gateway: <http://localhost:3000/api/v1/ready>; Mailpit: <http://localhost:8025>. Đây là URL đích **sau khi khởi chạy thành công**. Không có tài khoản test được seed trong phiên; đăng ký/kích hoạt qua luồng bình thường hoặc chuẩn bị tài khoản test đúng quy trình dự án, không lấy tài khoản từ DB cũ hay tự sửa quyền trong frontend. Chỉ bật writes trên dataset cô lập. `Ctrl+C` dừng các child process do launcher tạo.

Nếu chỉ mở FE theo cấu hình riêng, dùng `apps/{web,admin-cms}/integration.env.example`; `NEXT_PUBLIC_DATA_MODE=api`, `FRONTEND_API_ENV=local`, `FRONTEND_GATEWAY_URL=http://127.0.0.1:3000/api/v1`.
