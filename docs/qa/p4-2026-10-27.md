# Kết quả QA P4 — 2026-10-27

P4 đã qua kiểm thử local trên năm backend đã compile chạy trong Docker:
Auth, Gateway, Question Bank, Exam và Analytics. Hạ tầng thực gồm PostgreSQL 16,
Redis 7, RabbitMQ 3, MinIO và Elasticsearch 8.15. Node của runner là 22.15.0;
Node trong image là 22.23.4. Docker Desktop dùng khoảng 8 GB RAM cho VM.

E2E tạo nội dung bằng REST qua Gateway và login Auth thực, signed PUT trực tiếp
MinIO, chờ outbox/indexer rồi đọc search. Các ca bao gồm Full/1/nhiều/7 Part,
idempotency, owner/roles, header giả, Part 2, draft chỉ Redis, bỏ trống, immutable
snapshot, submit đồng thời một event, lịch sử theo mode, archive cascade và review
sau archive. Full/Part events đến Analytics với count/weighted weak areas khớp.
USER content và attempt đang làm không chứa đáp án, giải thích hay transcript.

## Smoke performance

Qua Gateway, concurrency 1, 5 warmup rồi 100 mixed reads (test list, search, Full
result) và 10 Full submissions mới:

| Đường đi    | Mẫu |       p95 |   Ngưỡng |
| ----------- | --: | --------: | -------: |
| Read        | 100 |  47.30 ms |  <500 ms |
| Full submit |  10 | 162.27 ms | <2000 ms |

Đây là smoke trên máy local, không xác nhận capacity/SLA sản xuất. Dữ liệu media
là fixture tổng hợp để thử upload/MIME/public URL. Điểm Full dùng bảng tham khảo
đã có disclaimer; Part luôn giữ scaled score null.

## Chạy lại và bằng chứng

Xem [hướng dẫn QA](../../scripts/qa/README.md). Các báo cáo local được bỏ khỏi Git:

- `artifacts/qa/latest.json`: E2E, timing và cleanup.
- `artifacts/qa/operational.json`: pause Redis/PostgreSQL và phục hồi.
- `artifacts/qa/seed.json`: đề demo và tài khoản QA.

Storage QA được tách bằng DB/index/bucket/exchange/queue riêng. E2E chỉ xóa ID
thuộc lần chạy; giữ search tombstone và Analytics inbox để chống xử lý lại.
Đề demo giữ lại có ID `a601873c-d890-4fca-b90b-90836d72a4e6`.

Backend CI đã bổ sung job migration và Docker E2E/smoke, upload JSON artifact.
GitHub Actions chưa chạy trong phiên này; trạng thái remote cần xác nhận sau push.
